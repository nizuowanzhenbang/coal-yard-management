# 煤场出场账面依据

部署方配置稳定且唯一的 `YARD_SOURCE_INSTANCE`，例如 `plant-a-yard-01`；未配置时导出返回503。登录用户调用 `POST /api/stock-out/{id}/accounting-evidence`，提交 `{"offset_minutes":480,"time_evidence":"原始记录使用北京时间的依据"}`。必须由操作者确认时区，同一偏移同时用于出场与所引用的入场时间。时间依据是调用者声明，不是自动识别。返回报文含时间、操作者、出场编号、去向原文、吨数和FIFO入场扣减明细，以及规范内容SHA256。

只有完成或审批通过的出场记录可导出；丢失、重复、不匹配或数量不守恒的记录返回409，请核实原账；此接口不修改数据。吨数精确到0.001吨，支持最大1万亿吨，严禁负数及非有限值。需要调用方自行保管导出，摘要仅标记内容变化，不是签名或真伪证明。入场记录信息来自导出时的当前数据库，若后续被修改，重新导出的内容可能不同或被拒绝；保管原响应以便回溯。

数据是库存账面FIFO，既不识别现场实际煤流、机组稳定身份、燃用区间，也不自动映射煤质系统批次或确认物理入炉。现有库存写路径并发、盘点与数量规则仍需单独加固。合成测试与CI不代表现场部署或实际运行收益。
